# 🌱 AgroSense Smart Irrigation System

## 📌 Project Overview
AgroSense is an IoT-based Smart Irrigation System designed to monitor soil moisture and help manage water usage efficiently. It provides a web dashboard for viewing sensor readings and controlling the irrigation pump.

## 🎯 Objectives
- Monitor soil moisture levels.
- Support automatic and manual irrigation pump control.
- Display temperature, humidity, and water tank levels.
- Provide live sensor monitoring and visual charts.
- Help reduce unnecessary water consumption.

## ✨ Features
- **Soil Moisture Monitoring:** View current soil moisture readings.
- **Automatic Mode:** Control irrigation based on the selected moisture threshold.
- **Manual Mode:** Allow users to control the pump manually.
- **Water Tank Monitoring:** Track the available water level.
- **Live Dashboard:** View sensor values and charts.
- **Activity History:** Track pump activity and system events.
- **Sensor Report:** Download a report of sensor readings.

## 🚀 How to Run
1. Install Node.js on your computer.
2. Download or clone this repository.
3. Open the backend folder in a terminal.
4. Run `npm install`.
5. Run `node server.js`.
6. Open `index.html` in your browser.

The backend runs locally at `http://localhost:3000`.
